Sistema de Control de Inventario Escolar

Aplicación de consola desarrollada en Python diseñada para administrar y controlar el inventario de suministros escolares de forma dinámica, permitiendo altas, modificaciones, bajas y consultas en tiempo real.

🚀 Características Principales

Gestión de Artículos: Permite registrar nuevos suministros o actualizar las existencias de los ya existentes.

Control de Existencias (CRUD básico): Capacidad para agregar, consultar y eliminar elementos del inventario.

Validación de Datos: Control de entradas vacías y verificación estricta de que las cantidades sean valores numéricos válidos.

Manejo de Errores: Bloques de control de excepciones (try/except/finally) para garantizar la robustez del programa frente a entradas incorrectas.

📂 Estructura del Script

El proyecto está contenido en un único script principal (quiz.5.11.py) que centraliza:

La inicialización de la estructura de datos en memoria (Diccionario).

El bucle interactivo de opciones mediante interfaz de línea de comandos (CLI).

Las validaciones de negocio y el control de excepciones.


🛠️ Requisitos del Sistema
Python 3.8 o superior instalado en el equipo.


⚙️ Guía de Ejecución
Clona o descarga el archivo quiz.5.11.py en tu equipo local.

Abre una terminal en la ruta donde se encuentra el archivo.

Ejecuta el programa con el siguiente comando:

Bash

python quiz.5.11.py

Utiliza el menú interactivo ingresando el número de la opción deseada (1 a 4) y sigue las instrucciones en pantalla.
